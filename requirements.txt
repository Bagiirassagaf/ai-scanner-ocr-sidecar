# Runs on its own Dockerfile-pinned Python (python:3.12.10-slim, matching
# ai-scanner's own image as of 2026-08-01) deliberately kept as its own
# service rather than merged into ai-scanner's own image -- PaddlePaddle's
# packaging lags new CPython releases significantly (see the OCR upgrade
# roadmap, §6.2): paddlepaddle==3.3.1 ships a cp312 wheel but not yet a
# cp314 one, so this sidecar can't simply track whatever Python ai-scanner
# uses in the future without re-checking PyPI first. Keeping this as its own
# small service also means ai-scanner's own dependency footprint stays lean
# and auditable (it stays a PII-handling service, not a multi-GB ML
# runtime), and this sidecar can be restarted/scaled/rolled back entirely
# independently.
# =============================================================================
